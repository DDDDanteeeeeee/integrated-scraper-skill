# 项目上下文

## 当前有效信息

- 交付物是可发布、可一键初始化的项目级 Codex Skill Pack，不是独立应用、控制平面或云服务。
- 目标是让用户为每次任务自由指定抖音账号、品牌、产品、关键词、话题或作品，
  并基于已验证的 OpenCLI 主采集与浏览器补充路径生成可审计的公开情报报告。
- Skill Pack 仅包含主 Skill、初始化器、透明依赖清单、配置样例、脚本与文档；所有运行数据和浏览器会话必须留在本机并被忽略。
- `dependencies.manifest.json` 是依赖角色、来源、许可证、版本策略和人工安装确认边界的唯一来源；它不是可复现的第三方二进制锁文件。
- `docs/delivery-guide.zh-cn.md` 是面向新电脑和非技术用户的标准交付路径；
  仓库名为 `douyin-intelligence-skill`，Skill 调用名为 `douyin-intelligence`。
- Magewell 与千视只是一条已跑通过的示例任务，不得成为其他用户或新任务的
  隐含研究对象、受益方或默认结论。
